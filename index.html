Embedded ML

Transmission and Reception of Signal Using ESP-32 with Machine Learning

Team of 3 · Presented at RASET 2026 (IEEE OES)

A low-cost direction-finding system: a trained classifier reads live RF signal-strength data from three ESP32 nodes and predicts the strongest signal path in real time.

  • Collected 17,270 labelled RSSI measurements across an indoor test environment, training on 13,816 and holding out 3,454 for evaluation.
  • Benchmarked four classifiers — Random Forest, SVM, KNN, and a 3-layer MLP — with the MLP reaching 99.97% test accuracy, a single error across 3,454 predictions.
  • Built a live Python dashboard with LED hardware indicators hitting 65ms end-to-end handover latency, then presented the work at RASET 2026, a national conference organized by IEEE OES.
